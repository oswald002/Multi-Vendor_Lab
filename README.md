# Multi-Vendor Enterprise Network Lab

A GNS3 lab simulating an enterprise network across multiple vendors,
built to demonstrate hands-on routing, switching and security skills.

## Skills demonstrated
- VLANs, RSTP, EtherChannel (LACP)
- First-hop redundancy (HSRP) with load balancing across VLANs
- OSPF with passive-interface hardening
- (Add later: eBGP, IPsec VPN, firewalls, multi-vendor interop)
